# Ligação com GitHub

Repositório: `leleca7/modo-protagonista-studio`.

O ChatGPT conectado ao GitHub pode revisar e alterar o código quando o usuário solicitar. O programa local, porém, não usa esta conversa como API em segundo plano.

## Recomendação de privacidade

Mantenha este repositório **privado**. Mesmo com `.gitignore`, não versione chaves, tokens, cookies, banco de projetos, arquivos de mídia ou renders.

## Atualização no computador

Depois de clonar o repositório, `ATUALIZAR_DO_GITHUB.bat` executa `git pull --ff-only`.

Para desenvolvimento visual e revisão de mudanças, GitHub Desktop também é uma opção.
